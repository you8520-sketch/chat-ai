## 공개본에서 제거한 것

원본 스냅샷(`snap-aN-rN-{before,after}.json`)은 공개 저장소에 올리지 않았다. 대신 필요한 필드만 추출해 `rounds/`에 넣었다.

- 제거: 초대 코드, 사용자·페르소나·호스트 id, 업로드 URL, 세션·쿠키·토큰, 세계관 브리프 원문, 과금·포인트 잔액, 캠페인 id, 브라우저 UI 크롬.
- 유지(편집 없이 원문): GM 서술, 사람 행동, 동료 locked action, 서버 판정, HP·위치·소지품, 지도 상태.
- 비밀번호·키는 사용한 적이 없다. 로그인은 사용자가 직접 한 기존 관리자 세션이었다.
- 원본은 저장소가 아니라 Cursor 에이전트 아티팩트(`trpg-prod-play-evidence/raw/`)에 있고, 그 파일의 sha256이 `ORIGINALS.sha256`과 일치한다.

## 읽을 때 알아야 할 것

- 플레이한 배포 SHA는 `794793b`(라운드 1~8), 라운드 9 중 `7a0c543`이다. #1632(`eb18d5a8`)는 포함하지 않는다. 그래서 라운드 3/4/8/9의 위치 불일치는 #1632 이전 동작이다.
- 읽기 전용 확인(이번 턴, `GET https://hav.chat/api/health`): `gitCommit "eb18d5a"`. 즉 현재 운영은 #1632를 포함한다(`git merge-base --is-ancestor eb18d5a8 origin/main` 통과). 이전 턴에는 `7a0c543`이었고 그 사이 다른 쪽에서 배포됐다. 이번 작업에서 배포한 것은 없다. 증거 플레이는 #1632 이전 빌드에서 이뤄졌고 #1632 이후 빌드로는 재플레이하지 않았다.
- 렌은 사람 테스트 입력이다. 일부 라운드(예: 라운드 3)에서 자유 텍스트가 서버 명령과 어긋난다.
- 동료 locked action `…은 제자리에 서서 상황을 살핀다.`는 서버가 쓴 문장이며 모델 출력이 아니다. 해당 11건은 모델 원문이 없다.
- 라운드 9는 운영 재배포로 GM 생성이 끊겼다가 같은 라운드가 재생성됐다. 끊기기 직전 시작 스냅샷이 없어 라운드 9 시작 전 상태는 라운드 8 종료 상태로 대체했고 해당 파일에 표시했다. 복구 직후 상태는 `rounds/round-09-errored-recovery-state.json`.
- 스크린샷 폭은 1280px(1440px 아님). 390px 화면에서 "최신으로" 알약이 하단 독 탭 라벨 위에 겹쳐 보인다(이전 보고서의 "독이 가리지 않는다"는 표현은 이 겹침을 과소평가했다).
- 서버 `mechanicsLines`는 모든 라운드에서 빈 배열이다. 이 필드는 위협 타격(`threatStrikes`)을 렌더링하지 않으므로 빈 배열은 타격 없음의 증거가 아니다.

## REPORT.md 정정

- 원 보고서: "라운드 6 지도에는 단서(clue)가 기록되었으나 GM 서술은 '쓸 만한 것이 없었다'로 단서 내용을 전달하지 않음."
- 정정: 라운드 6 GM 서술 첫 기록실 단락은 `'출구 빗장은 경보가 울린 뒤에만 풀린다.'`를 직접 인용한다. 같은 서술에 "탐나는 물자는 어디에도 보이지 않았다", "다른 보물 같은 수확은 없었지만"도 있다. 단서 전달 여부 판단은 [COMPARISON.md 3절](COMPARISON.md) 원문으로 GPT가 한다.
- 원 보고서의 "운영 미배포"는 작성 시점의 사실이며 위 읽기 전용 확인으로 현재는 해당하지 않는다.

## 확인된 사실 / 원인 미확정 / 별도 후속

확인된 사실(증거 파일에서 직접 확인):

- 라운드 3, 8, 9(렌)와 4(강이현 CRITICAL_FAILURE)에서 서버 지도는 이동을 적용했으나 시트 위치는 이전 방이었다. 같은 유형의 이동이 성공 티어이면 시트가 이동한다([COMPARISON.md 1절](COMPARISON.md)).
- 동료 슬롯 24개 중 11개가 서버 작성 대기 문장이다. 11개 모두 모델 원문 없음.
- 12라운드 동안 세 PC의 HP는 변하지 않았다. 승인된 위협 서술은 라운드 5/6에서 "빗나감"이다.
- 렌은 라운드 11에 출구(서버 위치 `출구`)에 도달했고 라운드 12에 대기했다. 캠페인은 종료되지 않았다(`ACTION_INPUT`).

원인 미확정(추측하지 않음):

- 대기 11건의 원인. 필요조건과 관측 한계는 [BOT_PATH_INVESTIGATION.md](BOT_PATH_INVESTIGATION.md).
- 위협 타격이 서버에서 굴려지고 HP가 적용/미적용됐는지. 타격 기록이 공개 스냅샷에 노출되지 않는다.
- GM 서술의 출구 위치(중앙홀 서편 등)가 서버 지도(출구는 `r1`, 남쪽복도·보관실과 연결, 중앙홀과 직접 연결 아님)와 다르게 읽히는 이유.

이번 PR과 별개인 후속 후보(착수하지 않음):

- 대기 경로에 원문·거절 사유 관측이 없음.

- 출구 도달을 종료로 연결하는 서버 경로가 없고 GM `campaign_finished` 또는 목표 확인에 의존.
