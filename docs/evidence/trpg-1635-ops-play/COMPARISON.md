## 4. GM 서술 vs 서버 위치 (발췌, 전문은 rounds/)

라운드 1 GM는 강이현의 배선 탐색 실패와 렌의 기둥 엄호, 권태현이 현관홀 중앙에 서 있음을 쓴다. 서버 위치도 전원 현관홀. 강이현 FAILURE와 서술의 허탕은 같은 방향을 가리킨다.

라운드 2 GM는 표지판에서 `[단서: 출구 빗장은 경보 후에만 풀린다]` 를 드러낸다. 서버 지도 markers는 여전히 빈 배열이고 alarm은 false다. 시트 위치는 현관홀.

라운드 3 GM 발췌: `경보실로 이어지는 우측 순환로 통로의 입구를 향해 과감하게 전진했다` … `권태현은 순환로 모퉁이에 어깨를 기댄 채`. 권태현 locked 본문도 순환로·경보실 방면을 향한다. 서버 시트 위치는 권태현 현관홀, 지도 current는 `r6`.
