- Eligible LAYERED path: S2 receives only `character` + `LOCKED_SECRET` chunks. CORE/ACTIVE drop those chunks.
- Unlabeled freeform Korean prose is PUBLIC. It is not S2. On default FULL_LEGACY it rides in the character canon string. On forced LAYERED this audit's `buildContext` slice did not include TOKEN_UNLABELED_FREEFORM, because it was not CORE and S2 rejected it.
- Regen/continue flags do not change visibility owners; they add other system directives. See the accompanying test.
