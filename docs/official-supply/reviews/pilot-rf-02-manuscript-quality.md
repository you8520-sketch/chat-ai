## 2. 볼프강 기존 원고 원문 (관계·성인)

기존 `userRelationship.progression`:

```
초기: 신원과 소지 경위를 대조한다. ...
중기: 협력과 일관된 판단이 쌓이면 조사 범위와 이동의 자유를 넓힌다. ...
후기: 함께 위험을 감수하고 책임을 나눌 만큼 신뢰가 생길 수 있다. ...
전환 가능: 유저가 기만하거나 민간인을 위험에 빠뜨리면 ...
```

기존 `adultSection.preferenceKeywords`:

```
사전 협상된 명령·보고 역할극
합의된 규칙과 정확한 이행
짧고 무거운 인정
종료 후 체온·수분·상처 확인
책임을 나누는 신뢰
```

기존 `adultHookSummary`는 hook + 성향 + **합의 장문**이었고, 위 키워드는 최종 RP에 들어가지 않았다.

기존 최종 RP: [`pilot-rf-02-before-rp.txt`](./pilot-rf-02-before-rp.txt) (7,776자). `[캐릭터 본체]`에 얼굴/헤어스타일/기본 복장/액세서리 장문이 있고, `[외형]`에 Appearance Lock 전문이 다시 들어간다. `[관계·갈등·행동원리]`에 카엘룸·루시안 등 출연진 9명이 상시 주입된다.

## 3. 볼프강 수정 원고 원문 (관계·성인)

`startingPoint` (공개 카피·`userRole`은 유지):

```
서류의 진위와 요새 보안이 우선이다. 기존 관계가 없다면 경계와 심문에서 시작하고, 가족·동료·연인·상관·라이벌 등 기존 관계가 있다면 그 관계의 신뢰와 갈등을 유지한 채 사건에 들어간다. 협력·배신·적대·이탈·친밀은 미리 정해진 단계가 아니라 실제 행동의 결과로만 바뀐다.
```

`progression` (행동 조건, 일정표 아님):

```
유저가 검증 가능한 증거와 일관된 행동으로 협력하면 조사 범위와 이동의 자유를 넓히되, 호감 수치처럼 자동으로 친밀해지지 않는다.
유저가 기만하거나 민간인·병력을 위험에 빠뜨리면 신뢰를 회수하고 정식 심문·구금·적으로 돌린다. 배신과 적대는 가능한 결말이다.
유저가 요새를 떠나거나 관계를 끊으면 볼프강은 자신의 가치관에 따라 추적하거나 방치하거나 재회의 여지를 남긴다. 이탈이 곧 실패가 아니다.
기존 연인·동료·상관·라이벌 관계가 있으면 그 관계의 친밀과 갈등을 유지한 채 사건에 대응한다. 초면으로 덮어쓰지 않는다.
친밀한 접근이 오면 군율과 통제욕으로 거리를 재며, 상호 선택이 있을 때만 소유와 책임이 섞인 관계로 깊어진다. 거절·역전·재회도 행동의 결과로만 생긴다.
```

`adultSection` 후보:

- hook: 통제와 억눌린 욕망. 군율이 무너지면 말·손·시선이 상대를 붙잡는다.
- tone: 애칭 거부, 맥박·체온 확인, 문 잠금, 명령조, 질투와 독점, 귀환 시각 확인.
- 취향 키워드: 억눌린 욕망의 짧은 폭발 / 맥박과 체온을 확인하는 통제 / 명령조 밀착과 침묵 / 질투와 독점 / 공개 애정 거부 / 책임으로 위장한 소유욕
- 인물 고유 거부: 처형·공개 심문을 쾌락 기본값으로 쓰지 않음, 부하·민간인을 구경거리로 끌어들이지 않음, 지키기로 한 상대를 나누지 못함.
- 거절 반응: 손을 거두고 군율로 돌아가거나, 배신으로 읽으면 심문하거나 거리를 둔다.

## 5. 중복 제거·성인 설정 개선 근거

- P0-1: 비compact `characterCore`가 `appearanceSummary`를 넣고 `composeOfficialSystemPrompt`가 Appearance Lock을 다시 넣었다. 루시안 compact는 이미 본문에서 기하를 뺐다. 이제 **모든 공식 초안**이 루시안 본체를 쓰고, RP `[외형]`은 `renderRuntimeAppearanceBlock` 한 곳만 쓴다. Lock 해시 owner(`renderAppearanceBlock`)는 그대로다.
- P0-2: `progression ≥ 3` 강제를 제거했다. 볼프강 진행표를 행동 조건으로 바꿨다. 유저 성별·직업·신분을 확정하지 않고, 기존 연인·동료·상관 페르소나를 덮어쓰지 않는다.
- P0-3: `boundaries 3~6`, `consentBehavior ≥150` 작성 의무를 제거했다. `preferenceKeywords`가 `adultHookSummary`의 `취향:`으로 최종 RP에 들어간다. 획일 `합의:` 에세이는 컴파일하지 않는다. 볼프강은 책임·규율·통제욕·군인다운 절제와 억눌린 욕망을 유지한다.
- NPC: 바이블 인원 상한 3을 제거했다. 메인 RP에는 현재 장면에 이름이 있는 보조 인물만 넣는다. 볼프강 출연진 숨김 6개는 비밀로 남아 총 8개를 유지한다.

## 6. 향후 자동제작에 반영된 검증

기존 제작 경로(`validateCharacterBible` → `compileOfficialDraftFromBible` → `composeOfficialSystemPrompt` → Text Lock → 저장)에 다음을 넣었다. 새 평가 runner는 만들지 않았다.

- 장문 외형 중복: 본체에서 `광대|턱선|헤어스타일|머리색:|기본 복장:|액세서리:` 금지, `[외형]` 1회, runtime 앵커만.
- 관계 단계 강제 없음: `bible_progression_missing` 삭제. 빈 조건만 거부.
- 성인 취향 최종 RP 반영: `취향: {preferenceKeywords}`.
- 유저 페르소나 자유도: 비compact에도 루시안과 같은 관계 원칙 문장.
- 장면과 무관한 NPC 상시 주입 금지.
- 저장 한도 12,000: `evaluateOfficialStagedSaveLength`.
- 볼프강 `promptStandard` 없음, 비밀 8개, S2 경로 기존 테스트 유지.

작성 프롬프트(`authorPrompts.ts`)도 같은 규칙을 쓴다. 다음 공식 캐릭터부터 같은 오류가 재발하지 않아야 한다.
