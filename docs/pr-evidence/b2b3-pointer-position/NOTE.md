# 탐험 버튼의 일반 스크롤·클릭·터치

이 기록은 배포된 production 빌드 `d341c13d7c1055f6a4b38bf1feb190c2a2fd490f`와 격리 DB의 기존 캠페인에서, 유료 모델 호출 0회로 확인한 조작 결과다. UI 소스는 바꾸지 않았다. 제출 요청은 브라우저에서 끊었으므로 라운드가 커밋되거나 모델이 호출되지 않았다.

조작은 휠 또는 터치 드래그로 버튼을 목표 바와 명령 독 사이, 또는 독 패널의 보이는 영역으로 옮긴 뒤 `elementFromPoint`가 그 버튼을 가리킬 때 마우스 클릭 또는 터치 탭을 했다. `force` 클릭, `element.click()`, `dispatchEvent`, React 핸들러 직접 호출, 가리는 요소를 숨기는 방법은 쓰지 않았다.

최초 입장에서 따라가기가 문서 끝으로 보내면 접힌 탐험 지도는 화면 위에 있다. 1440에서는 중심 y=-126, 독은 y=419–900이다. 390에서는 중심 y=-227, 목표 바 아래 231, 독 위 318이다. 위로 스크롤하면 지도 버튼이 그 사이에 들어오고 포인터를 받는다.

## 1440×900 마우스

- 지도 펼치기: 스크롤 4479, 중심 (182, 194), 안전 구간 117–419, `elementFromPoint`는 `탐험 지도`. 클릭 뒤 `expanded`.
- 출구 `골목으로 이동 1`: 중심 (194, 373), `elementFromPoint`가 그 버튼. 클릭 뒤 제출 예정 1.
- 조사, 대기열 비우기, 행동 탭, 내 시트 탭도 같은 방식으로 포인터를 받았다.
- 방식 입력: `조심스럽게 확인만 한다.`
- 제출: 중심 (318, 873), `elementFromPoint`는 `행동 제출`. 클릭이 `POST /api/trpg/campaigns/1/action`을 만들었고, 브라우저가 그 요청을 끊었다.
- 새로고침 뒤에도 휠로 지도 버튼을 구간 안에 두고 클릭하면 펼쳐졌다.

## 390×844 터치

- 지도 펼치기: 중심 (195, 364), 목표 바 231과 독 367 사이, trusted click, `expanded`.
- 독이 펼쳐진 상태에서 출구: 중심 (92, 345), 독 위 367, `elementFromPoint`는 `골목으로 이동 1`. 탭 뒤 대기열 `1. 골목으로 이동`.
- 조사와 대기열 비우기, 내 시트 탭과 행동 탭은 trusted click이었다.
- 독 패널을 터치로 스크롤한 뒤 방식 입력 `터치로 방식만 적는다.`
- 제출: 중심 (199, 812), `elementFromPoint`는 `행동 제출`, trusted click. 브라우저가 action POST를 끊었다.
- 새로고침 뒤 중심 (195, 270), 구간 231–367, `elementFromPoint`는 `탐험 지도` `펼치기`. 탭 뒤 `expanded`.
